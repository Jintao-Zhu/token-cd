# Recent experiment archive

This branch collects locally available recent OpenVLA, SpatialVLA, pi0-FAST and pi0.5 experiment scripts and summary reports in `research/semantic_token_cd`, `scripts`, and `docs`. The JSON files in this directory preserve selected per-call latency summaries; see their timing scopes and configurations before comparing models. The pi0.5 benchmark compares compiled and uncompiled execution paths, so its ratio is not an isolated algorithmic overhead.

Raw rollout datasets, model checkpoints, local logs and fixed observation files are not included. Some scripts and reports reference local absolute paths and require environment-specific adaptation; summary files may refer to artifacts not distributed in this branch. No complete reproduction run was performed for this archive.
