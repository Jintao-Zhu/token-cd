## 4. 结论

1. **最优区间 λ=0.50–0.75**（同口径 53.9% / 54.1%，统计上打平），显著优于 vanilla（净 +37 / +39，p<0.001）。
2. **过冲起点在 0.75–1.00 之间**：λ=1.00 已回到 vanilla 水平（48.2%，净 −8，p=0.51）。
3. **λ=1.25 / 1.50 显著劣于 vanilla**（43.7% / 44.2%，净 −44 / −40，p<0.001）——强引导纯有害。
4. **最优 λ 任务异质**：stack_cube 峰在 **1.00**（50.0%，净 +16）；spoon 在 **0.50**（36.4%）；carrot 在 **0.50–0.75**（34.7%）；eggplant 已饱和（vanilla 99.1%）**任何引导都掉分**，λ=1.50 掉到 80.3%。
5. 若要单一总表口径：**λ=0.75（54.1%）**；若允许按任务调参，则按第 3 节分别取。
