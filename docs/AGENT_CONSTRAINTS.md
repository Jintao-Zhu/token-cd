# 硬约束（Agent 必读）

**用户明确授权与禁止的 GPU 使用范围。违反过一次（2026-10-13 在 GPU0 起进程），务必不要再犯。**

| GPU | 状态 | 说明 |
|---|---|---|
| **0** | ❌ **禁止使用** | 用户从未授权。不要因为"空闲"就自作主张占用。 |
| **1 / 2 / 3** | ✅ **授权使用** | 用户明确："可以在 1、2、3 卡上再加进程"。可在此加进程/起服务。 |
| **4 / 5 / 6 / 7** | ❌ **禁止触碰** | 属于其他用户（zxr 的 CAVF / RLinf 训练）。绝不起进程、绝不 kill。 |

其它纪律：

- 起任何新进程前，先确认它落在 GPU 1/2/3 上；不确定就先问用户。
- 只杀自己起的进程（`pi0_fast_*`、`spatialvla_*_lambda_*`、`pi0_intact_*` 等），不要动别人的。
- 显存判断以 `nvidia-smi` 为准，保留安全余量（单卡 < 75GB）。
