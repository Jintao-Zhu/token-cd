## 结论

* λ=0.5：Matched 明显优于**数量过小**（fixed016，净 −40，Holm 显著）；
  与 fixed048、top_p090 的观测差异（+1.5pp / +1.0pp）在 Holm 校正后不显著。
  **不显著不等于等效**：这些差异的区间仍未排除几个百分点的可能性。
* λ=1.0：Matched 相对 fixed016/fixed048 的观测差异回到 0 附近（−1.25pp / −0.25pp），
  但 top_p090 反而高出 6.25pp（Holm 校正后仍不显著）。
* λ×规则**交互本身**（同 task/seed 配对估计，Holm 校正 4 个规则）：
  fixed016 **I=+11.25pp，Holm p=0.021（显著）**；random_fixed48 I=+9.00pp，Holm p=0.058；
  top_p090 I=+7.25pp，Holm p=0.130；fixed048 I=+1.75pp，Holm p=0.661。
  也就是说：**「预算过小」的代价随 λ 增大而缩小，这一点目前有配对证据支持**；
  「Matched 对 λ 不敏感」或「强引导下数量维度差异消失」在这批数据上**没有**得到检验，
  不应作为结论使用（Matched 只测了 λ=0.5 与 1.0 两点）。
* 内容与数量的分离只能由 fixed048 vs random_fixed48 给出（同数量、不同内容排序）；
  Matched vs random_fixed48 同时改变了数量规则与内容，不能单独归因于其中一项。
