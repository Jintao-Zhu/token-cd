## 4. 结论

1. **6 个 matched 臂全部优于 vanilla**（配对净胜 +12 ~ +27），λ=1.00 最优（188/500=37.6%，p=0.0028 最显著）。
2. **λ≥1.25 出现过冲**：净胜降到 +12/+17，p 不再显著（0.24 / 0.075）→ 拐点落在 1.00–1.25 之间。
3. **增益高度任务相关**：pick_coke_can 从 19/100 → 36~40/100（最大来源）；open_drawer +3~4；close_drawer 完全饱和持平；move_near 仅 λ=1.00 有 +4。
4. **place_apple 全线失效**：vanilla 1/100，所有 matched 臂 0/100 —— 该任务在本 checkpoint 下不可解，建议单列说明（不参与均值解释）。
5. 分任务最优 λ 明显异质：close_drawer 偏好 1.25/1.50（62/100），move_near/pick_coke 偏好 1.00，open_drawer 偏好 0.25–1.00 —— 与 SpatialVLA/OpenVLA 上的异质性结论一致。
